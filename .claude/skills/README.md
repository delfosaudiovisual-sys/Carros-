# Skills de design e animação usadas neste projeto

Skills copiadas de repositórios públicos do GitHub para guiar o trabalho de interface e de animação do app.
Cada pasta mantém a licença original.

| Pasta | Origem | Licença | Para que serve aqui |
|---|---|---|---|
| `frontend-design` | [anthropics/skills](https://github.com/anthropics/skills) | Apache 2.0 | Direção visual, tipografia e evitar cara de modelo pronto |
| `emil-design-eng` | [emilkowalski/skills](https://github.com/emilkowalski/skills) | MIT | Acabamento de interface: curvas de easing, `:active`, `@starting-style`, origem das animações |
| `animate` (+ `RECIPES.md`) | [emilkowalski/skills](https://github.com/emilkowalski/skills) | MIT | Decidir se, quanto e como animar (troca de carro, menus, painel) |
| `review-animations` | [emilkowalski/skills](https://github.com/emilkowalski/skills) | MIT | Revisão das animações existentes |
| `animation-performance` | [emilkowalski/skills](https://github.com/emilkowalski/skills) | MIT | Animar só `transform`/`opacity`, custo de `blur`, `will-change` |
| `mobile-native` | [emilkowalski/skills](https://github.com/emilkowalski/skills) | MIT | Celular: `100dvh`, hover só com mouse, sem flash de toque, inputs de 16 px |
| `threejs-animation` | [CloudAI-X/threejs-skills](https://github.com/CloudAI-X/threejs-skills) | MIT | Animação procedural (motor girando, portas, explosão das peças) |
| `threejs-interaction` | [CloudAI-X/threejs-skills](https://github.com/CloudAI-X/threejs-skills) | MIT | Seleção de peças por raycasting e controles de câmera |
| `threejs-lighting` | [CloudAI-X/threejs-skills](https://github.com/CloudAI-X/threejs-skills) | MIT | Luz ambiente, sombras e reflexos |
| `threejs-performance` | [CloudAI-X/threejs-skills](https://github.com/CloudAI-X/threejs-skills) | MIT | Instancing dos parafusos, limpeza de memória ao trocar de carro |

Também avaliadas e não copiadas: [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill),
[Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill), [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills)
e [freshtechbro/claudedesignskills](https://github.com/freshtechbro/claudedesignskills). São bons, mas cobrem o mesmo terreno
das escolhidas ou são voltados a React/landing pages, e este app é uma página única em JavaScript puro com three.js.
